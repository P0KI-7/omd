# Домашнее задание №1

## Версия Python
Python 3.10+ (у меня 3.11.9)

## Установка зависимостей
Программа использует только стандартную библиотеку Python (модуль `math`). Сторонние зависимости не требуются.

## Как запустить из корня репозитория
Для проверки работы всех сценариев (демонстрации) перейдите в папку с заданием и запустите основной файл:
```bash
cd hw_3
python hw_classes_base.py
```

## Описание
В этом задании реализована система для обработки текста и выделения ключевых слов на основе статистики TF-IDF.
Файл `hw_classes_base.py` содержит следующие классы:
- `CountVectorizer` — подсчет частот слов (из семинара)
- `BinaryVectorizer` — бинарный вектор присутствия слов (из семинара)
- `TfidfVectorizer` — вычисление весов TF-IDF с поддержкой настройки `use_idf` и конфигурации.
- `KeywordExtractor` — извлечение топ-N ключевых слов из текста на основе весов векторизатора.
