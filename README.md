# Домашние задания по Python

Этот репозиторий содержит решения домашних заданий по курсу Python.

## Структура репозитория

- `hw_1/` — Домашнее задание №1 (Основы языка Python)
- `hw_2/` — Домашнее задание №2 (Функции)

Инструкции по установке зависимостей и запуску находятся в `README.md` внутри каждой папки с заданием.
